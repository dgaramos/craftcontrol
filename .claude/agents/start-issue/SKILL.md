# Start issue

Verify the issue has an assignee, label, milestone, and GitHub Project. Read `README.md`, every Markdown file in `roadmap/`, `CLAUDE.md`, `AGENTS.md`, `CONTRIBUTING.md`, and `docs/architecture.md` for every issue. Read every affected file completely. Create `{number}-{type}/{short-description}` from updated `main`. Stop for missing metadata or unclear acceptance criteria.
