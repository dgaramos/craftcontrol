# Create issue

Clarify the user impact, scope, non-goals, affected layers, dependencies, and verifiable acceptance criteria. Create the issue with Context, Task, Expected outcome, and Given/When/Then criteria. Set Project, Milestone, Label, and Assignee before considering it ready. Do not create an issue without explicit user approval of material scope choices.
