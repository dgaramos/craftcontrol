# Manage milestone

List milestones and open issues before making a change. Choose by delivery scope: Reliable Foundation for reliability/security, Clean Architecture for modular refactoring, Complete Panel for product UI, and Community Ready for onboarding, diagnostics, and release work. Confirm an assignment before changing it.
