# Manage milestone

List milestones and open issues before making a change. Choose by delivery scope: Fundação Confiável for reliability/security, Arquitetura Limpa for modular refactoring, Painel Completo for product UI, and Community Ready for onboarding, diagnostics, and release work. Confirm an assignment before changing it.
