# Handle PR findings

Read the exact review context and verify each finding against the current diff. Classify it as blocker, simple improvement, or out of scope. Apply one focused commit per accepted finding, run the relevant gate, push only with user confirmation, and reply or resolve threads with evidence. Create a follow-up issue for valid out-of-scope work.
