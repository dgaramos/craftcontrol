# CraftControl

> Esta é a versão em Português (Brasil). Consulte o [README em inglês](README.md)
> como referência canônica para a documentação técnica e operacional.

CraftControl é um centro de controle responsivo, pensado primeiro para celulares,
para servidores Minecraft Bedrock. Ele permite administrar mundos, jogadores,
regras, acesso, backups e estatísticas de jogo sem depender do console do servidor.

## Documentação em tradução

Esta tradução acompanha o README principal. Enquanto a versão completa é
finalizada, use o [README em inglês](README.md) para instruções de instalação,
configuração, operações e recuperação.
